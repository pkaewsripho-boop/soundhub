# Thai Voice Studio

โปรแกรมพิมพ์ข้อความแล้วให้ AI อ่านเป็นเสียงพากย์ภาษาไทย ดาวน์โหลดเป็น MP3 พร้อมไฟล์ซับ .srt ได้
ติดตั้งไว้บนคอมเครื่องเดียว คอมหรือมือถือเครื่องอื่นในวงแลนเดียวกันเปิดใช้ผ่านเบราว์เซอร์ได้ ไม่มีค่ารายเดือน

## ติดตั้งครั้งแรก (Windows)

1. ติดตั้ง Python 3.10 ขึ้นไปจาก https://www.python.org/downloads/
   ตอนติดตั้ง **ต้องติ๊ก "Add python.exe to PATH"**
2. แตกไฟล์ zip นี้ไว้ในโฟลเดอร์ไหนก็ได้
3. ดับเบิลคลิก `start-windows.bat`
   - ครั้งแรกจะใช้เวลาติดตั้งประมาณ 1 นาที
   - ถ้า Windows ถามเรื่อง Firewall ให้กด **Allow** สำหรับ Private network (จำเป็นสำหรับเครื่องอื่นในวงแลน)
4. เบราว์เซอร์จะเปิดขึ้นมาเอง

Mac / Linux: เปิด Terminal ในโฟลเดอร์นี้แล้วรัน `./start-mac-linux.sh`

## ใช้จากเครื่องอื่นในวงแลน

หน้าต่างดำที่เปิดค้างไว้จะแสดงที่อยู่ เช่น

```
เครื่องอื่นในวงแลน: http://192.168.1.25:7860
```

พิมพ์ที่อยู่นี้ในเบราว์เซอร์ของมือถือหรือคอมเครื่องอื่นที่ต่อ Wi-Fi/แลนเดียวกัน
ต้องเปิดหน้าต่างโปรแกรมค้างไว้บนเครื่องหลักตลอดเวลาที่ใช้งาน

## วิธีใช้

- **พิมพ์ข้อความ** ได้สูงสุด 20,000 ตัวอักษรต่อครั้ง กด `Ctrl+Enter` เพื่อสร้างเสียง
- **เลือกเสียง** มีเสียงไทยหญิง/ชาย กดปุ่ม ▶ เพื่อฟังตัวอย่าง
  "เสียงหลายภาษา (ทดลอง)" อ่านไทยได้แต่อาจมีสำเนียงต่างชาติ ลองฟังก่อนใช้
- **โทนเสียง** เป็นค่าสำเร็จรูป เช่น สารคดี ลึกลับ ตื่นเต้น หรือปรับเองด้วยแถบความเร็ว ระดับเสียง ความดัง
- **ให้หยุดหายใจ** ขึ้นบรรทัดใหม่ หรือใส่ `…` / `,` ในจุดที่อยากให้เว้น
- **อ่านผิด?** สะกดตามเสียงอ่านแทน เช่น เขียน "เอไอ" แทน "AI", "สองพันห้าร้อย" แทน "2,500"
- **ไฟล์ .srt** นำเข้าโปรแกรมตัดต่อ (CapCut, Premiere) เพื่อได้ซับตรงกับเสียง แบ่งเป็นประโยค
- **ประวัติ** ทุกเครื่องในวงแลนเห็นรายการเดียวกัน ฟังซ้ำ ดาวน์โหลดซ้ำ หรือลบได้

ไฟล์ทั้งหมดเก็บอยู่ในโฟลเดอร์ `outputs` ข้างโปรแกรม

## ข้อควรรู้

- เครื่องที่รันโปรแกรมต้อง **ต่ออินเทอร์เน็ต** เพราะเสียงสร้างโดยบริการเสียง AI ของ Microsoft ผ่านไลบรารี `edge-tts`
- บริการนี้ฟรี แต่ไม่ใช่บริการที่ Microsoft เปิดให้ใช้อย่างเป็นทางการ อาจเปลี่ยนแปลงหรือใช้ไม่ได้ในอนาคต
  ถ้าวันหนึ่งสร้างเสียงไม่ได้ ลองอัปเดตด้วยคำสั่ง
  `.venv\Scripts\python.exe -m pip install -U edge-tts` แล้วเปิดโปรแกรมใหม่
- ทุกคนในวงแลนที่รู้ที่อยู่สามารถใช้ได้ ไม่มีรหัสผ่าน
- เปลี่ยนพอร์ต: `start-windows.bat --port 8080`

## เอาขึ้นออนไลน์ฟรี (Hugging Face Spaces) — เปิดใช้ได้ทุกที่ผ่านลิงก์

1. สมัครฟรีที่ https://huggingface.co/join
2. ไปที่ https://huggingface.co/new-space
   - **Space name:** เช่น `thai-voice-studio`
   - **SDK:** เลือก **Docker** → **Blank**
   - **Hardware:** CPU basic (ฟรี)
   - **Visibility:** Public (ระบบรหัสผ่านในข้อ 4 จะกันคนอื่นไว้ให้)
   - กด **Create Space**
3. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้: แท็บ **Files** → **Add file** → **Upload files** → ลากไฟล์ทั้งหมดมาวาง → **Commit**
   (รวมถึงโฟลเดอร์ `static` และไฟล์ `Dockerfile`)
4. **ตั้งรหัสผ่าน (สำคัญ):** แท็บ **Settings** → **Variables and secrets** → **New secret**
   - Name: `APP_PASSWORD`  Value: รหัสผ่านที่ต้องการ
5. รอประมาณ 2–3 นาทีให้สถานะเป็น **Running**
6. เปิดใช้ที่ลิงก์ `https://ชื่อผู้ใช้-thai-voice-studio.hf.space`
   (กดเมนู ⋮ มุมขวาบนของหน้า Space → **Embed this Space** จะเห็นลิงก์ตรง ใช้ลิงก์นี้ดีที่สุด และเพิ่มลงหน้าจอโฮมมือถือได้)

ข้อจำกัดของแบบฟรี:
- ถ้าไม่มีคนใช้ 48 ชั่วโมง Space จะหลับ เปิดลิงก์แล้วรอ ~1 นาทีให้ตื่น
- พื้นที่เก็บไฟล์ไม่ถาวร เมื่อ Space รีสตาร์ท **ประวัติและไฟล์เสียงเก่าจะหาย** ให้ดาวน์โหลดเก็บไว้ทุกครั้ง
- เก็บไฟล์ล่าสุด 300 รายการ (เปลี่ยนได้ด้วย Variable `MAX_HISTORY`)
- Microsoft อาจจำกัดการใช้งานจากเซิร์ฟเวอร์คลาวด์ ถ้าสร้างเสียงไม่ได้ ให้ไปที่ Settings → **Factory rebuild**

ถ้าเก็บโค้ดไว้บน GitHub ด้วย: แก้ที่ GitHub แล้วอัปไฟล์ที่แก้ไปที่ Space อีกครั้ง Space จะสร้างใหม่ให้อัตโนมัติ

### ใช้รหัสผ่านในวงแลนด้วย (ไม่บังคับ)
Windows: เปิด Command Prompt ในโฟลเดอร์นี้ แล้วพิมพ์
```
set APP_PASSWORD=รหัสของคุณ
start-windows.bat
```
